Quản trị Learning Hubs

Chỉ người có mã khóa GitHub (token) của repo mới sửa được nội dung.

Chưa có mã khóa? Cách tạo (3 phút)
  1. Mở trang tạo token (đăng nhập GitHub).
  2. Token name: learning-hub-admin. Expiration: chọn 90 days hoặc 1 year.
  3. Repository access: Only select repositories → chọn learning-hub.
  4. Permissions → Repository permissions → Contents: chọn Read and write. Không cần quyền nào khác.
  5. Bấm Generate token, copy mã github_pat_... dán vào ô bên trên.

Mã chỉ lưu trong trình duyệt của bạn, không gửi đi đâu ngoài GitHub. Không chia sẻ mã này cho ai.
